# Collections

Collections in Python is ways for us to store larger data sets or "collections" of data in one common place or variable. We do this using different data collection types:

- List
- Dictionary
- Set

## List

A list in python is a unordered collection of data, We can use this to store many variables or objects inside the same variable, This is very useful when we have a large amount of data we want to transfer between functions or classes in python without needing to know either the size or having to write each value as a parameter.

A list in python is created like this:

```python
my_list = list()
# or with "list-comprehension"
my_list = []
```
